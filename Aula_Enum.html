Dominando ENUM em Java

Estudo de Caso Prático: Sistema de Notas Escolares

Conceito Fundamental

O que é um Enum em Java?

Um **Enum** (Abreviação para *Enumeration*) é um tipo especial de classe em Java utilizado para definir um **conjunto fixo e imutável de constantes relativas a um determinado domínio**.

No nosso exemplo escolar, um aluno não pode ter um estado arbitrário (como "QUASE_PASSOU" ou um número aleatório 99). A situação é estritamente delimitada em apenas 3 opções válidas:

Média ≥ 7.0

APROVADO

"Aluno aprovado com sucesso! Boas férias."

Ação: Emitir Certificado
4.0 ≤ Média < 7.0

RECUPERACAO

"Aluno em recuperação. Necessário realizar nova avaliação."

Ação: Prova Substitutiva
Média < 4.0

REPROVADO

"Aluno reprovado por média insuficiente."

Ação: Matrícula em Dependência

Anatomia de um Enum Avançado em Java

Constantes Pré-definidas APROVADO, RECUPERACAO, REPROVADO
Campos/Atributos private final String mensagem;
Métodos Próprios avaliarNota(double media)
Enum/SituacaoAluno.java
Java 5+ 
package Enum;

public enum SituacaoAluno {
    APROVADO("Aluno aprovado com sucesso! Boas férias."),
    RECUPERACAO("Aluno em recuperação. Necessário realizar nova avaliação."),
    REPROVADO("Aluno reprovado por média insuficiente.");

    private final String mensagem;

    // Construtor do enum (Sempre privado implicitamente ou explicitamente)
    SituacaoAluno(String mensagem) {
        this.mensagem = mensagem;
    }

    public String getMensagem() {
        return mensagem;
    }

    // Método estático para definir a situação com base na nota numérica
    public static SituacaoAluno avaliarNota(double media) {
        if (media >= 7.0) {
            return APROVADO;
        } else if (media >= 4.0) {
            return RECUPERACAO;
        } else {
            return REPROVADO;
        }
    }
}

Destaques do Código

1. Declaração das Constantes

Cada constante passa seu parâmetro direto ao construtor: APROVADO("...").

2. Atributo `final`

Como enums são imutáveis, os atributos são marcados como private final para garantir a integridade dos dados.

3. Construtor Privado

O construtor do enum é chamado automaticamente na inicialização da aplicação para cada opção declarada. Nunca usaremos new SituacaoAluno()!

4. Método Estático (`avaliarNota`)

Encapsula a regra de negócio da escola (cortes 7.0 e 4.0), retornando diretamente o objeto do Enum correto.

Enum/Escola.java
Classe Principal 
package Enum;

public class Escola {
    public static void main(String[] args) {
        double notaDoAluno = 5.5; // Exemplo de nota

        // Chamada estática do Enum para obter o estado
        SituacaoAluno situacao = SituacaoAluno.avaliarNota(notaDoAluno);

        System.out.println("Média do aluno: " + notaDoAluno);
        System.out.println("Situação: " + situacao);
        System.out.println("Detalhe: " + situacao.getMensagem());

        System.out.println("\n--- Ações do Sistema ---");

        // Utilizando switch para tomar decisões baseadas no enum
        switch (situacao) {
            case APROVADO:
                System.out.println(">> Emitindo certificado de conclusão...");
                break;
            case RECUPERACAO:
                System.out.println(">> Gerando agendamento para a prova substitutiva...");
                break;
            case REPROVADO:
                System.out.println(">> Matriculando o aluno na dependência/retenção...");
                break;
        }
    }
}

Integração e Uso do Switch

Atenção: No comando switch(situacao), o Java já sabe o tipo do Enum. Por isso, usa-se apenas case APROVADO: em vez de case SituacaoAluno.APROVADO:!

Fluxo de Execução:

  1. Definição: Guarda a nota 5.5 na variável local.
  2. Avaliação: Passa a nota para SituacaoAluno.avaliarNota(5.5), que retorna a constante RECUPERACAO.
  3. Impressão: Exibe o nome da constante e a sua mensagem customizada associada.
  4. Ramificação: O switch entra estritamente no bloco correspondente para acionar a ação do sistema.

Segurança de Tipo (Type Safety)

Impede erros em tempo de compilação! Se um método espera SituacaoAluno, você só pode passar um dos 3 valores do Enum. Nada de números mágicos (ex: 99) ou textos com erros de digitação (ex: "aprovadoo").

Encapsulamento e Organização

A regra de negócio (média ≥ 7.0 para aprovação) fica centralizada dentro de SituacaoAluno.avaliarNota(). Se os critérios mudarem amanhã, você altera em um único arquivo do projeto.

Integração Perfeita com Switch

O compilador Java verifica todas as opções no switch(situacao), permitindo criar rotas de execução limpas, legíveis e sem acoplamento.

Comparativo: Constantes Tradicionais vs. ENUM

Característica Constantes Antigas (public static final int) Java ENUM (Abordagem Moderna)
Validação de Tipos Fraca (Aceita qualquer int) Forte (Aceita apenas valores do Enum)
Comportamento/Métodos Impossível (Apenas guarda o valor) Pode ter métodos, construtores e atributos
Leitura no Log/Console Exibe números sem contexto (ex: "1") Exibe a constante literal (ex: "APROVADO")
